## File & Directory Descriptions

### Root

| File | Description |
|------|-------------|
| `.eslintrc.json` | ESLint configuration defining linting rules and parser options for the project. |
| `.gitignore` | Specifies files and directories excluded from Git version control. |
| `README.md` | Project overview, setup instructions, and developer documentation. |
| `next-env.d.ts` | Auto-generated TypeScript declaration file for Next.js environment types. |
| `next.config.mjs` | Next.js framework configuration (routing, image domains, environment variables, etc.). |
| `package.json` | Project metadata, npm scripts, and dependency declarations. |
| `postcss.config.mjs` | PostCSS configuration, typically used to integrate Tailwind CSS and Autoprefixer. |
| `tailwind.config.ts` | Tailwind CSS configuration including theme customisation, content paths, and plugins. |
| `tsconfig.json` | TypeScript compiler options and path alias definitions for the project. |
| `tsconfig.tsbuildinfo` | Incremental TypeScript build cache file generated by the compiler. |

---

### `src/app/`

Next.js App Router root. Contains route groups, global styles, and the root layout.

| Path | Description |
|------|-------------|
| `(app)/` | Route group for authenticated application pages (dashboards, settings, etc.). |
| `(auth)/` | Route group for authentication-related pages (login, register, password reset). |
| `(marketing)/` | Route group for public-facing marketing and landing pages. |
| `globals.css` | Global CSS stylesheet; imports Tailwind base, components, and utilities. |
| `layout.tsx` | Root layout component wrapping all routes with shared HTML structure and providers. |
| `page.tsx` | Root entry page, typically redirects or renders the default landing view. |

---

### `src/components/`

Reusable React components organised by concern.

| Path | Description |
|------|-------------|
| `common/` | Shared, general-purpose components used across multiple route groups. |
| `layout/` | Structural layout components such as headers, sidebars, footers, and navigation. |
| `marketing/` | Components specific to marketing and public-facing pages (hero sections, CTAs, etc.). |
| `ui/` | Low-level, design-system UI primitives (buttons, inputs, modals, badges, etc.). |
| `providers.tsx` | Composes and exports all React context providers (auth, query client, theme, etc.). |

---

### `src/lib/`

Utility libraries, API clients, and custom hooks.

| Path | Description |
|------|-------------|
| `api/` | API client modules, request helpers, and service-layer abstractions. |
| `hooks/` | Custom React hooks encapsulating reusable stateful or side-effect logic. |
| `utils/` | Pure utility and helper functions (formatting, validation, date handling, etc.). |

---

### `src/stores/`

Global client-side state management stores.

| File | Description |
|------|-------------|
| `auth.store.ts` | Zustand (or similar) store managing authentication state (user session, tokens). |
| `org.store.ts` | Store managing organisation-level state (active org, membership, settings). |

---

### `src/types/`

Shared TypeScript type definitions.

| File | Description |
|------|-------------|
| `api.types.ts` | TypeScript interfaces and types for API request/response payloads and data models. |
